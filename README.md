# 🏋️‍♂️ Eeshletics — Performance Gym Website

Eeshletics is a modern, fully responsive frontend gym website designed to deliver a premium user experience with high-end UI/UX, smooth animations, and interactive features.

Built as a portfolio-level project, it represents a real-world fitness brand concept based in Karachi, Pakistan.

---

## 🚀 Live Preview
https://eesha1625.github.io/eeshletics-gym-website/

---

## 📌 Features

- Modern Hero Section with animated typography  
- Glassmorphism-based UI (Join Form Card)  
- Dark/Light Theme Toggle  
- Dynamic Stats Counter  
- Built-in BMI Calculator  
- Multi-page Navigation  
- Fully Responsive Design  
- Smooth Animations & Transitions  
- Services, Trainers & Pricing Pages  
- Interactive Contact Form  

---

## 🧠 Technologies Used

- HTML5 — Structure  
- CSS3 — Styling (Flexbox, Grid, Animations)  
- JavaScript (Vanilla JS) — Interactivity  
- Google Fonts — Typography  

---

## 🎨 UI/UX Highlights

- Glassmorphism effects with blur & transparency  
- Animated radial gradient background  
- Typing text animation in hero section  
- Hover-based micro-interactions  
- Clean and structured layout

## ⚙️ How to Run Locally

1. Clone the repository:
git clone https://github.com/eesha1625/eeshletics-gym-website.git

2. Open the folder:
cd repo-eeshletics-gym-website

3. Run:
Open index.html in your browser

---

## 🌐 Deployment (GitHub Pages)

1. Go to Settings → Pages  
2. Select branch: main  
3. Save  

 site will be live at:
https://eesha1625.github.io/eeshletics-gym-website/
